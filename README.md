# 全球天然气（Henry Hub / TTF 代理）贸易研判与风险预警系统

> **项目定位**：基于 Python 的量化研判**原型**，覆盖「多源公开数据采集 → 清洗治理 → 供需平衡建模 → 方向概率预测 → 风险标签 → 自动化 HTML 研报」全流程，用于全球天然气（Henry Hub / TTF 代理）的方向性研判与风险预警。
>
> **免责声明**：本项目为个人研究项目，输出**不构成任何交易建议**。方向概率预测不代表价格点位预测，请勿据此进行实际交易决策。

---

## 1. 目录结构

```
.
├── data/
│   ├── raw/                  # 原始下载数据：只追加、永不覆盖
│   └── processed/            # 清洗对齐后数据集、特征表、供需平衡表
├── scripts/
│   ├── collect/              # 采集脚本（重试、增量缓存、限流）
│   ├── data_pipeline/        # 清洗、时间对齐、频率转换
│   ├── feature_model/        # 供需指标、特征工程、建模、滚动回测
│   └── report_render/        # HTML 周报自动生成、图表渲染
├── docs/                     # 数据字典、清洗日志、回测报告、一页纸简报、情景样本
├── requirements.txt          # 依赖清单（用途 + 最低版本）
├── .env.example              # 环境变量示例（仅占位符，无真实 Key）
└── README.md                 # 本文件
```

> 空目录以 `.gitkeep` 占位保留结构。

## 2. 数据源清单

| 数据域 | 数据源 | 用途 | 说明 |
| --- | --- | --- | --- |
| 美国天然气价格 / 库存 / 供需 | EIA（美国能源信息署）公开数据 | Henry Hub 价格、周度存储、供需平衡输入 | 使用公开 API / 数据集，需 `EIA_API_KEY` |
| TTF 代理 | GIE AGSI（欧盟天然气基础设施·储气）公开数据 | 以欧盟储气数据作为 TTF 方向研判的代理特征 | 需 `GIE_AGSI_API_KEY` |

**数据红线**：仅使用公开免费数据；禁用付费数据；TTF 研判仅使用欧盟储气代理，不直接使用付费 TTF 行情。

## 3. 环境配置步骤

1. 创建虚拟环境（建议使用项目自带工具，不直接改全局 Python）：
   - Windows：`python -m venv .venv`，激活 `.venv\Scripts\activate`
   - macOS/Linux：`python3 -m venv .venv`，激活 `source .venv/bin/activate`
2. 安装依赖：`pip install -r requirements.txt`
3. 加载 `.env`（**API Key 只读自环境变量，禁止硬编码进脚本**）：
   - 复制示例：`copy .env.example .env`（Windows）或 `cp .env.example .env`（macOS/Linux）
   - 在 `.env` 中填入真实值：`EIA_API_KEY=...`、`GIE_AGSI_API_KEY=...`
   - 脚本内通过 `python-dotenv` 的 `load_dotenv()` 与 `os.environ[...]` 只读加载。
   - **真实 `.env` 不得提交到版本控制**。

## 4. 阶段说明（P0–P6，顺序推进，前一阶段验收通过才进入下一阶段）

| 阶段 | 内容 | 关键产出 |
| --- | --- | --- |
| P0 | 立项与环境：项目骨架、依赖与环境配置 | 目录骨架、requirements、.env.example、README |
| P1 | 数据采集：重试、增量缓存、限流、只追加入库 | `data/raw` 原始数据、采集脚本 |
| P2 | 数据治理：清洗、时间对齐、频率转换、缺失处理 | `data/processed` 对齐数据集、数据字典、清洗日志 |
| P3 | 指标与建模：L1 供需平衡表 + 库存偏离度 SD；L2 特征工程；L3 v1 规则压力评分 + v2 方向概率双模型；Walk-Forward 回测 | 供需平衡表、供需指标、特征表、方向概率模型、回测报告 |
| P4 | 风控评估：分情景命中率、随机/惯性双基准、ROC-AUC、特征重要性、≥2 失效案例复盘 | 风控评估报告、失效案例复盘 |
| P5 | 报告工程：HTML 周报 + 3 份历史情景样本 + 一页纸简报 | HTML 周报、历史情景样本、一页纸简报 |
| P6 | 总验收：全流程贯通与红线合规复核 | 总验收结论 |

## 5. 红线提醒（全流程必须遵守）

1. **禁点位预测**：只输出方向概率 / 风险标签，不做价格点位预测。
2. **禁用付费数据**：TTF 仅使用欧盟储气（GIE AGSI）代理。
3. **滞后中国数据禁入周度特征**：避免数据滞后污染周度特征。
4. **Walk-Forward 回测**：模型验证必须使用滚动前推回测，禁止信息泄露。
5. **data/raw 只追加、永不覆盖**：原始数据不可被清洗流程覆写。
6. **API Key 只读环境变量**：禁止硬编码到脚本；`.env.example` 只用占位符。
7. **全部折算留痕**：任何单位/汇率/频率折算需在清洗日志中留痕。
8. **个人研究不构成交易建议**：所有输出需注明「个人研究项目，输出不构成交易建议」。
