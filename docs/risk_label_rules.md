# 风险标签规则表（Risk Label Rules）

> 个人研究项目，输出不构成交易建议。本表定义 P5 报告工程可直接引用的 4 类风险标签，
> 每条含「触发条件 + 等级 + 来源特征 + 阈值 + OOS 触发周数」。触发周内的模型命中率仅作
> **描述性参考**（小样本、非标签信号的回测），不代表标签本身有预测效力。

## 0. 口径

- 阈值基于全历史（特征可用起）分位数/z 分，属**描述性监控规则**，非回测优化出的交易规则。
- z 分 = (当期值 - 全历史均值) / 全历史标准差；滚动 Z 用 52 周窗口。
- OOS 触发周数统计窗口 = 2022-01-14 ~ 2026-10-02（247 周）。
- 等级：**黄（关注）** = 超 ±1σ / P75；**红（警戒）** = 超 ±2σ / P95。

## 2. 逐条说明与注意事项

### R1 寒潮持续（Cold Snap）
- **含义**：HDD 4 周异常 z 分 +1 以上表明当前 4 周累计取暖需求显著高于历史同期，偏看多压力。
- **注意**：P4 发现 `hdd_anomaly_4wk` 在 1 周方向标签上符号与直觉相反（首窗相关系数 -0.18），
  故本标签**只作"天气偏冷"的事实标记**，不直接映射为方向看多；与 v1 联动时需先修正符号问题。
- **触发周内模型命中率（描述性）**：黄 27 周 v1/logit/lgbm = 0.556/0.667/0.667；红 7 周 = 0.429/0.714/1.000。

### R2 LNG 出口扰动（LNG Export Shock）
- **含义**：LNG 出口相对自身 52 周趋势的滚动 Z 跌破 -1 表示出口骤降（如 Freeport 停产），偏看空压力；
  跌破 -2 为强扰动。对称地，+1/+2 表示出口激增（偏看多）。
- **注意**：LNG 出口为**月频且滞后 1–2 月**（EIA v2 无周频路由），本标签是**回溯性/滞后**监控，
  不具实时性；阈值按 52 周滚动 Z 去趋势（出口长期上台阶）。
- **触发周内模型命中率（描述性）**：黄 13 周 = 0.615/0.462/0.769；红 3 周 = 0.667/0.333/1.000。

### R3 欧盟储气低位（EU Storage Low）
- **含义**：欧盟充满度相对历史同周的偏离 z 分 ≤ -1 表示欧盟储气显著偏低，欧洲竞争性采购可能增加，偏看多压力。
- **注意（重要）**：**红级（-2σ）在 2022–2026 OOS 期从未触发（0 周）**，阈值过严、无区分度。
  建议改为 **-1.5σ**，或叠加绝对水平触发（如 `gie_full_pct < 40%`）作为红级。黄级 38 周有实际触发。
- **触发周内模型命中率（描述性）**：黄 38 周 = 0.500/0.579/0.579。

### R4 高波动区间（High Volatility）
- **含义**：HH 周收益 8 周滚动标准差超历史 P75/P95，表示波动放大，**方向信号置信度应整体下调**（适用所有模型）。
- **注意**：**黄级（P75）触发 128/247 周（52%）**，几乎不具选择性——因 2022–2026 波动整体偏高，历史 P75 门槛偏低。
  建议改用**滚动分位数/滚动 P90** 或按年度重估阈值；红级（P95）27 周较有区分度。
- **触发周内模型命中率（描述性）**：黄 128 周 = 0.570/0.523/0.586；红 27 周 = 0.667/0.556/0.778。

## 3. 组合使用建议（供 P5，非交易建议）

1. **R4 红（高波动）优先**：波动极端时，方向模型（v1/v2）置信度整体降级，报告应突出"方向不确定性"而非方向。
2. **R1+R3 同时触发**：欧盟低位 + 寒潮持续 → 偏看多压力共振，但需先修复 hdd 符号问题后方可叠加。
3. **R2 红（LNG 出口骤降）**：与 Freeport 类事件强相关，属看空/看多取决于方向（骤降偏空、激增偏多），且为滞后标签，仅作事后归因。
4. 所有标签**只作风险暴露提示**，不与任何点位/仓位挂钩。
